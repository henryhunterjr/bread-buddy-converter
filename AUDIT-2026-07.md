# Bread Buddy Converter — Full Audit & Stabilization (July 2026)

A top-to-bottom audit of the conversion math, parser, stability, and UI, with fixes
applied and a permanent regression test suite added (`npm test`, 40 tests).

## Conversion math — verified and fixed

The core lean-dough conversion (yeast → sourdough at 100% starter hydration) was
**verified correct by hand**: 500g flour / 350g water / 10g salt / 7g yeast produces a
40g starter + 80g water + 80g flour levain (exactly 100% hydration, 20% inoculation)
and a 400g flour + 250g water final dough. Hydration preserved at 70.0%.

These bugs produced **wrong numbers** and are now fixed:

1. **Plural volume units silently failed** — "2 cups bread flour" parsed as **2 grams**
   of flour because the unit table only matched singular forms. Units are now
   normalized (cups/tablespoons/teaspoons/oz/lb/kg/l all recognized) and converted
   through a per-ingredient density table.
2. **Non-100% starter hydration used the wrong flour ratio** — the levain build used
   the water fraction for flour, so an 80%-hydration starter produced ~504g of real
   flour in a "500g" recipe and a levain labeled 100% that was actually 95.7%.
3. **Baker's percentages double-counted the levain** — the composite "all of the
   levain" row (40%) was listed on top of its component rows (8% + 16% + 16%).
4. **Contradictory starter warnings** — the converter targeted 20% inoculation
   (levain flour ÷ total flour) while a second warning system measured levain
   *weight* ÷ flour and flagged the converter's own output as "40% — too high."
   Both now use the flour basis.
5. **Kosher salt at 2× density** — "1 tbsp kosher salt" converted at 20g (table-salt
   density); now 14.4g (Morton). A correct recipe no longer trips the salt warning.
6. **ml treated as grams for all liquids** — 120ml honey was 120g (real: ~170g).
   Honey, syrup, molasses, and oil now use real densities.
7. **Milk counted as 100% water** — hydration on milk breads overstated by ~5 points;
   now 87% (whole milk), consistently in both directions of conversion.
8. **Starter water converted into milk** — in sourdough → yeast conversions with
   multiple liquids, the starter's water was redistributed proportionally across all
   liquids, silently increasing milk. It now returns to the water line only.
9. **"Dissolve yeast in 1/4 cup warm water"** added ~59g of unaccounted water; the
   step now says to use the recipe's own water.
10. **"(optional)" dough ingredients were silently dropped**, changing totals.
11. **Zero-flour input produced NaN** displayed in the UI; guarded everywhere.
12. **Enriched-dough hydration advice contradicted itself** (one module said target
    70–75%, another warned above 68%); unified to 60–70% typical.

## Stability & UX fixes

- Public **analytics dashboard and partner pitch deck links removed** from the
  consumer landing page footer.
- Dead **client-side password gate deleted** (it logged the correct password to the
  browser console).
- **"Dough Type" selector removed** — it was never wired to anything; users choosing
  "Enriched" got identical output to "Straight."
- **Quick measurement converter lag fixed** — results always trailed one keystroke
  behind the input (stale-closure bug).
- **Starter breakdown display** now respects the selected starter hydration instead
  of hardcoding 50/50.
- Saved recipes: corrupt localStorage entries no longer crash the list; stale
  titles/descriptions no longer bleed between conversions; UUID ids.
- OCR worker leak on failed image extraction fixed (try/finally).
- Hero image: 1.7MB PNG → 82KB WebP; logo 479KB → 12KB. Biggest page-load win.
- Removed all diagnostic console noise; accessibility labels added to icon buttons;
  copyright unified and year made dynamic.

## On "bilingual"

The app has **no interface translation**. What it does have is recipe-term
recognition for Italian sourdough vocabulary (lievito madre, primo/secondo impasto),
which is preserved. If a true bilingual UI is wanted (e.g., English/Spanish), that is
a separate build — flagged for decision.

## Test suite

`npm test` runs 40 unit tests covering both conversion directions, hydration
preservation, starter-hydration variants, enriched doughs, multi-liquid recipes,
volume/weight unit conversion, densities, egg handling, and degenerate input.
Run before every deploy.
